# Listora for EmDash

**Included in Free**

Listora is a directory for an EmDash site. Visitors search listings. Members add and manage their own. You approve what goes live.

The plugin is the engine and the admin screens. The pages visitors open come from a site kit you copy in. [Set up Listora on your site](getting-started/install.md) is the first page.
