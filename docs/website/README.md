# Listora for EmDash

**Included in Free**

Listora for EmDash is a directory plugin for EmDash sites. Visitors search listings. Owners submit and manage them. Admins moderate. It is a new TypeScript plugin, not WordPress Listora running inside Astro.

Install from the EmDash collection as `@vapvarun.bsky.social/listora`, then copy the site kit so the site has `/listings/` pages. The plugin alone ships routes, storage, and Block Kit admin.

Listora is Free only and at version 0.5.2. Install it from the EmDash registry as `@vapvarun.bsky.social/listora`. Readiness and QA live in [QA catalog](how-to/qa-catalog.md).

## Two products

| Product | Stack | Docs |
| --- | --- | --- |
| WB Listora | WordPress, PHP, Gutenberg | [wb-listora](https://github.com/wbcomdesigns/wb-listora) |
| Listora for EmDash | Astro, TypeScript, Block Kit | this repo |

Do not port PHP. Port jobs and chrome.
