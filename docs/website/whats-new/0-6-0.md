# 0.6.0

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.6.0`. GitHub tag `v0.6.0`. Copy the kit again after you update: `scripts/add-to-site.sh /path/to/your/site`. That copy replaces `src/lib/listora-strings.ts`, so keep a copy of any wording you changed and put it back.

- **Safer website links.** A listing's website must be a full address starting with http:// or https://. The add form, edit requests and the CSV import refuse anything else, and a listing page never shows another kind of address as a link.
- **Settings in tabs.** Submissions, Listing lifetime, Photos, Messages, and Import and export each have their own tab and one Save.
- **Lists that scale.** The listings queue, reviews, claims and messages each have Find and show 25 at a time with Load more.
- **Reword the directory in one file.** Every phrase a visitor sees is in `src/lib/listora-strings.ts`. See [Reword the directory](../customize/wording.md).
