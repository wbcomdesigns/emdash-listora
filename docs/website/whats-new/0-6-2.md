# 0.6.2

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.6.2`. GitHub tag `v0.6.2`. Copy the kit again after you update, with the new tag, as the [install guide](../getting-started/install.md) shows. If you changed `listora-strings.ts`, the setup command now keeps your copy as `listora-strings.ts.bak-YYYYMMDD`; an untouched file is replaced without a backup.

- **Set up visitor pages.** Admin, Listora, Get started opens with the one command that copies the site kit for the version you installed, the addresses it adds, and the install guide. Press **Visitor pages are set up** when they work, and **Show the setup steps again** after an update.
- **Clear admin names.** The admin group is named Listora, and its reviews page is Listing reviews, so it is not confused with WB Reviews.
- **Sample queue that works.** Load sample directory adds two listings waiting for approval, and both approve. A queue row whose listing was deleted or is in Trash offers only Remove from the queue, after a confirm. A stale second decision from another admin tab is refused.
- **Empty directory.** A directory with no listings says so and invites the first listing, instead of "No listings match".
- **Dark mode buttons.** Buttons and selected chips use your theme's brand colour and its text colour, so they stay readable in dark mode.
- **Safer submissions.** Every field of a new listing is cleaned and capped. The public health check writes nothing and no longer shows the waiting count.
