# 0.7.0

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.7.0`. GitHub tag `v0.7.0`. Copy the kit again after you update, with the new tag, as the [install guide](../getting-started/install.md) shows.

- **Fits Cloudflare's limit.** On Cloudflare Workers each plugin call gets 10 requests to the site. Every Listora page, action, hook and scheduled task now makes 9 or fewer, on a directory of 2000 listings, measured by its tests. It has not yet been walked on a Cloudflare site, so the install guide still says Cloudflare is not supported.
- **Your data comes over by itself.** After the update, Listora builds a directory index and carries ratings and waiting notices over, a step a minute. Admin screens say so with a banner and keep working. The directory routes of the plugin API ask callers to try again until the index is built; the kit's own pages are not affected.
- **Owner changes and photos have their own pages.** Admin, Listora, Listing changes shows each change as the value now and after approval. Listing photos shows each picture. Every admin list pages with Next and Previous, however long it is.
- **A decision cut off part way comes back on the next click.** An item left "being approved" is put back in its list when you click it again after five minutes, to decide again.
- **The owner's view of their listing.** The member who manages a listing sees You manage this listing, with a way to their account, instead of Claim and Write a review. A listing a member adds counts as theirs, shows as claimed, and nobody else can claim it.
- **Guests.** A guest sees Sign in in place of the review and claim forms. Messages from guests need a visitor address from the host: on Node set `trustedProxyHeaders` (see the install guide).
- **The account page** loads one tab at a time, with More for reviews of your listings and for messages. Delete my data runs in parts until everything is gone.
- **Expiry dates are kept by Listora,** so a listings type without an `expires_at` field still expires listings.
- **Export and import** handle a directory of any size: the import page downloads every listing and sends a file a few rows at a time.

The owner decision on whether member-added listings count as claimed (issue #83) is one setting in the code, `SUBMITTER_IS_OWNER` in `src/lib/types.ts`, on by default.
