# 0.5.3

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.5.3`. GitHub tag `v0.5.3`. Copy the kit again after you update: `scripts/add-to-site.sh /path/to/your/site`.

- A listing's website is only ever a full web address starting with http:// or https://. The listing page never shows a website link that could run code, a CSV import refuses such a row with a clear reason, and an edit request leaves it out.
- The directory's server-side calls go to your site's own address from EmDash settings, never to an address a visitor's request names. On a live site, set **Settings**, **Site URL**. On your own computer (localhost) nothing needs setting.
