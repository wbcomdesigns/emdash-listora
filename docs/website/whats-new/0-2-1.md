Released 2026-10-13 as `@vapvarun.bsky.social/listora@0.2.1`. GitHub tag `v0.2.1`. Testers install this version, not `0.1.0` or `0.2.0`. Copy `site-kit/` again so the chrome lands.

Ignore older registry versions. After install, copy `site-kit/` and open `/listings/`.
