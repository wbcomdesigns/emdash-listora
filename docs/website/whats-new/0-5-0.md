# 0.5.0

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.5.0`. GitHub tag `v0.5.0`. Run `scripts/add-to-site.sh` again after you update.

New permissions: sending email, reading and assigning categories, and adding files to the media library.

- Owner tools in the account: edit a listing, add photos, read messages, reply to reviews, renew. Edits, photos and replies wait for approval
- Photos on a listing with a large view
- Listing expiry, with an email a week before
- An hourly email to an owner when messages are waiting
- Browse by category and by city
- Listing pages show the details of their type: event dates, bedrooms and price, cuisine, salary
- Import and export as a spreadsheet at `/listings/import/`
- Settings page, dashboard card, admin lists with Load more and find
- One setup command and a one-page install guide
- Optional Listings block for post and page text
- The site's own time zone for hours and events

The full list is in the [changelog](https://github.com/wbcomdesigns/emdash-listora/blob/main/CHANGELOG.md).
