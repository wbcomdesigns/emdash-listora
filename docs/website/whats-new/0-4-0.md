# 0.4.0

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.4.0`. GitHub tag `v0.4.0`. Copy `site-kit/` again after you update, including `site-kit/public/vendor/`.

- Paging: 24 listings per page with Previous and Next. No more cut-off at 80 listings
- Messages admin page for what visitors send from a listing
- The map library ships inside the kit
- Ratings live in the plugin's own storage and update at once
- The account and submit pages are never cached
- Bathrooms field restored on the submit form

Before adding Listora to a live site, read "Before you add it to a live site" in `site-kit/README.md`.
