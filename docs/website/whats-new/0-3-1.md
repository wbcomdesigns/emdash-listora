# 0.3.1

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.3.1`. GitHub tag `v0.3.1`. No kit changes.

- Approving a review or a claim no longer publishes unfinished edits on the listing. The rating catches up after the listing is published
- A bad record cannot stop the Listora admin pages from loading
- Members can only review, save or claim a public listing
- The dashboard only names a listing that is public or that the member submitted
