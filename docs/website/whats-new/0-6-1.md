# 0.6.1

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.6.1`. GitHub tag `v0.6.1`. Copy the kit again after you update: `scripts/add-to-site.sh /path/to/your/site`. Keep a copy of any wording you changed in `listora-strings.ts` and put it back.

- **Safer map popups.** The directory map and the listing page map show the listing title as plain text. Before, a title containing markup could run code in a visitor's browser when they opened the pin.
- **Plain email addresses.** Emails typed into the add form, claims and messages must be a plain address. A message link in your account can no longer carry extra recipients.
- **Owner changes respected.** After a claim moves a listing, renewing and the edit form follow the new owner.
