# 0.6.3

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.6.3`. GitHub tag `v0.6.3`. Copy the kit again after you update, with the new tag, as the [install guide](../getting-started/install.md) shows. Kit files you changed are kept as dated backups; untouched files are replaced.

- **Approvals that were cut off come back.** If an approval stops part way (a failed write, or the request running out of time), the listing returns to the queue and its counts within five minutes, and Approve works on it again. Two admins clicking at once still get one decision. Photos waiting get the same treatment.
- **Account tabs on a phone.** The account tabs and the counts on its overview wrap onto a second row on a narrow screen, so every tab is in view.
- **Full review count.** Reviews of your listings shows the newest 10 per listing. When a listing has more, a line names the full count and links to the listing, where every review is listed.
- **Import and export on a fresh site.** Before the site address is known (a fresh site before its first restart), Settings names the `/listings/import/` page instead of showing no way there.
- **Small fixes.** More reviews has space above the Write a review form. A damaged reviews page link gets a plain message. The kit setup command says that backups of files under `public/` go to `.listora-backups/`.
