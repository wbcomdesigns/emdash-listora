# 0.3.0

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.3.0`. GitHub tag `v0.3.0`. Copy `site-kit/` again after you update. The pages and the CSS changed.

- Members act as their signed-in account. Guests browse and can message a listing
- Submitting with moderation off publishes the listing
- Review approval updates the listing rating. Claim approval marks the listing claimed and sets its owner
- Reviews and Claims admin pages load with rows, and show the listing name and the full text
- Dark mode follows the site theme. Search icons no longer overlap the placeholder
- Import, export and the claims list need an admin
- Registry listing has an icon, banner, screenshots and install steps

Routes changed. See [Plugin routes](../developer-guide/routes.md).
