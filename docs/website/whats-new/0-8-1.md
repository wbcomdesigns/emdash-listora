# 0.8.1

**Included in Free**

Released as `@vapvarun.bsky.social/listora@0.8.1`. GitHub tag `v0.8.1`. Copy the kit again after you update, with the new tag, as the [install guide](../getting-started/install.md) shows. No new permissions. On Cloudflare, redeploy after the update.

## What changed

- **A listing's email stays private.** The email a member types on the add form is kept for the listing's owner and for you in the admin. It is no longer in the public directory routes or on the listing page, and the add form says "Not shown on the listing page or in the directory." Visitors reach the owner through **Contact**.
- **The add form starts on your default type.** Settings, Listings, **Default listing type** is the type chosen first on the add form.
- **The Listings queue tells listings apart.** Each row shows **Where** (address and city) and **Sent by** (the member's account email), so two listings with the same title no longer look the same.
- **A waiting claim shows as waiting.** A member who sent a claim sees "Your claim is waiting for approval" on the listing instead of the form. Sending again changes nothing.
- **Long words wrap.** A review, title or message that is one long word breaks inside its box on the listing page, and in the Listing reviews, Claims, Messages and Listings queue tables, where the decision column now comes second.
- **Limits are stated.** Reviews, claim proof and messages take up to 1,000 characters, review titles up to 120. The forms stop at the limit and say so, and a longer request is refused in plain words instead of being cut.
- **No upgrade note on a new install.** A new site with nothing to bring over no longer shows "Bringing your data over".
- **Plainer admin wording.** Saving the Listings settings says "Listing settings saved." Admin lists page with **Next page** and **Previous page**. A message on a listing nobody manages reads "No owner to notify".
- **One rule for GitHub numbers.** On Software listings, live GitHub stars and the latest release replace the owner's values only when they are ahead of them, the same on the card, the header and Details.
